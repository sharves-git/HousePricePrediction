# House Price Prediction

A Machine Learning project that predicts house prices using the Ames Housing Dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- UV

## Project Workflow

Dataset
→ Data Cleaning
→ EDA
→ Feature Engineering
→ Linear Regression
→ Ridge Regression
→ Lasso Regression
→ Evaluation
→ Model Saving

## Evaluation Metrics

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- Cross Validation

## Generated Outputs

- Price Distribution Plot
- Correlation Heatmap
- Feature Importance Plot
- Actual vs Predicted Plot
